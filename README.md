# 📊 Statistics & Data Analysis with Python

A hands-on Python project covering fundamental concepts of **Statistics, Exploratory Data Analysis (EDA), Data Visualization, and Hypothesis Testing** using real datasets.

This repository contains Jupyter/Google Colab notebooks where I explored statistical concepts programmatically using Python libraries such as **NumPy, Pandas, Seaborn and Matplotlib**.

The goal of this project is to understand how statistical concepts can be applied to real datasets and how Python can be used to analyze, visualize, and interpret data.

---

##  Project Overview

Statistics is an important foundation for Data Science and Machine Learning.

In this project, I practiced:

- Descriptive Statistics
- Mean, Median, and Mode
- Data Exploration
- Data Visualization
- Box Plots
- Histograms
- Distribution Analysis
- Pair Plots
- Correlation Analysis
- Hypothesis Testing
- One-Sample t-Test
- P-values
- Significance Level
- Decision Making using Hypothesis Testing

The analysis is implemented using Python in Jupyter/Google Colab notebooks.
